# 几何卡牌初稿

本组图片由项目中的 `tools/generate_cards.c` 使用 raylib 自行绘制，没有使用下载的第三方素材。
每张 PNG 为 512×512，正面依次是青色沙漏、三角形、正方形、菱形、星星、六边形、十字、圆环、月牙、爱心、闪电、花朵；back.png 为统一卡背。

游戏通过编号加载 00.png 至 11.png，配对仍比较编号。可替换同名 PNG，不必修改配对算法。所有正面和卡背应一起提供；资源不完整时报告加载失败。项目构建后将卡牌复制到 EXE 旁的 assets/cards。

生成器有自己的 main，不加入游戏的编译列表；需要重新生成时，使用同样的 raylib x64 配置单独编译，并在项目目录运行。生成操作会覆盖本目录同名图片。
